# lessons.md

Distilled failure root-causes — the **actionable half**. Read before non-trivial work.

This file is loaded on **every session**, so it has a budget: keep it under ~3,000 tokens.
Split each lesson across two files:

- **here** — `## title` plus `**How to avoid**`. Imperative, with the exact command, port or
  path that makes it actionable. This is the half that changes behaviour.
- **`references/lessons-archive.md`** — `**What failed**` / `**Why**`, under the same title.
  Never preloaded. Read it when you need the mechanism: to generalise a rule, or to judge
  whether it still applies.

When the budget is hit, don't delete: merge lessons that share a root cause, tighten the
`How to avoid` wording, and move anything that looks stale into an archive section headed
`## Possibly stale — needs a human ruling` for a human to rule on. A lesson you delete is one you get to learn
again the hard way.
